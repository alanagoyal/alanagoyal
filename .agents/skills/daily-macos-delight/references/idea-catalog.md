# Idea Catalog

Use these as prompts for repository-aware ideation, not as required tasks. Confirm the behavior is absent and appropriate before selecting it.

## Micro: default choice

- Add one real System Settings row that controls an existing behavior, such as Dock magnification, menu-bar clock detail, sidebar icon size, or reduced motion.
- Add a functional Finder detail: path bar, status bar, sort/group control, rename interaction, or selection rectangle.
- Add a desktop or Dock detail: contextual menu, open-app indicator refinement, bounce feedback, trash behavior, or minimized-window affordance.
- Add one menu-bar command that visibly works in the focused app without introducing a keyboard shortcut.
- Add a native-feeling empty, loading, offline, or permission state to an existing app.
- Add a small accessibility improvement that does not introduce keyboard commands: clearer focus rings, reduced motion, larger hit targets, stronger contrast, or better labels.
- Add a personal but grounded detail using repository content: a Photos memory grouping, a Music listening note, an About panel detail, or a Finder file that reveals part of the owner's work.

## Small: occasional

- Add a visible Quick Look control for an existing Finder file type.
- Add a compact Spotlight-like launcher for apps and repository-backed content.
- Add a useful cross-app handoff, such as opening a Finder document in Preview/TextEdit or linking a Calendar item to Notes.
- Add one coherent macOS window behavior, such as a constrained tiling action or a better fullscreen transition.
- Add one meaningful view to an existing app, such as Calendar agenda, Photos favorites, Music recently played, or Settings search.
- Add a small desktop personalization control that immediately changes the shell and persists through the established storage layer.

## Larger: rare

- Add a compact app only when it exposes meaningful personal content or unlocks several existing assets. Calculator, Contacts, or a lightweight Safari-style portfolio browser may fit; a decorative clone does not.
- Add a cross-desktop system such as Mission Control only when it can be implemented and verified without destabilizing window management.

## Variation prompts

When recent work clusters in one area, deliberately inspect another:

- shell versus app;
- visual versus interaction;
- pointer versus touch;
- fidelity versus personal storytelling;
- discoverability versus depth;
- desktop versus mobile fallback.

Favor details that invite exploration and reward a second click. Avoid controls that look authentic but do nothing.
